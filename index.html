VS CODE DEV ADVENTURE: CYBERPUNK ELITE

Bem-vindo, Netrunner. Estamos em 2088. A megacorporação OmniCorp assumiu o controle da rede global de dados, aprisionando a humanidade em um algoritmo de vigilância em massa.

Sua missão é infiltrar os servidores centrais, escalar privilégios e derrubar o sistema corporativo.

Como Jogar:

  • Clique no botão "Escrever Código" na barra lateral ou aperte F5 / Espaço para gerar Linhas de Código (LOC).
  • Gaste LOC para comprar Extensões que geram código automáticas por segundo (CPS).
  • Evolua na Tech Tree para aprender conceitos reais de Programação, Cibersegurança e Arquitetura de Software.
  • Use o painel de Invasão (Traceroute) para invadir nós da OmniCorp e coletar Bounties em Créditos Corporativos!
Guia do Netrunner (Ajuda)

Painel Explorador (Pasta): Mostra seus recursos principais (Linhas de Código, XP, Créditos e Nível).

Extensões (🧩): Automatizam sua produção de código. Quanto mais extensões comprar, mais rápido seu bot de invasão roda sozinho.

Tech Tree (🌳): O lugar onde você aprende programação real. Cada tecnologia desbloqueada aumenta drasticamente o ganho de XP e LOC.

Traceroute / Invasão (🌐): Mini-game estratégico onde você conecta nós de rede em sequência antes que o firewall detecte a invasão.

Temas (🎨): Alterne entre o padrão Cyberpunk, Tokyo Night e Dracula na barra superior.
